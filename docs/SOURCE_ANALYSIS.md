# Reference analysis and adaptation

## Material examined

Repository: https://github.com/ai-playbooks/historical-documentary-video-workflow

Read on 2026-11-03: README.md (blob d897a4b8297b47815295f3ca959542caa4aa6e6d) and SYSTEM_PROMPT.md (blob 9a730f9dc45018446aae2445de4016c700c057e0). This analysis describes those versions, not future changes.

The reference is a browser-agent playbook rather than an executable application. Its core combines historical explanation with a making/building process. It uses a photorealistic presenter, animated watercolor illustrations, explicit timed labor, precise tools/costumes/architecture, inspected keyframes and narration-led timeline assembly.

## Decisions

| Reference mechanism | Cooking adaptation | Reason |
|---|---|---|
| History + construction | History + recipe execution | Keeps food preparation central to the investigation |
| Workers move material to a destination | Cook moves a specific ingredient between named vessels | Makes contact and transformation visible |
| Construction-stage lock | Food-state and quantity ledger | Prevents raw/cooked reversals and disappearing ingredients |
| Costume/architecture locks | Cook/hands, kitchen, utensil and vessel locks | Preserves identity and spatial continuity |
| Three timed shots per 10 seconds | One main action; optional feasible multi-shot beats | Fine hand work needs readable contact and time |
| Inspected image before animation | Verified pre-action culinary keyframe | Avoids starting with an already-cracked egg or already-poured flour |
| Fixed speaking presenter intro | Optional cook reveal; default off-screen narration | Fits The Last Forgotten Feast and hands-only production |
| Five-minute cap | Episode-specific runtime; short individual clips | Supports the channel's longer historical investigations |
| Muted documentary clip audio | Retained/mixed culinary ASMR | Cooking sound carries meaningful sensory detail |
| Unchanged narration; trim excess video | Preserve approved audio and match visual coverage | Protects script integrity during visual revisions |
| Service-specific browser execution | Prompt-first, optional authorized execution | Does not pretend service access exists |
